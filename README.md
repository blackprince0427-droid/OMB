# OMB

小型辦公軟件開發流程。每一版計劃書與開發文檔獨立保存，不覆蓋舊版。

## 現行依據

- 計劃書：V1.22（`計劃書版本/小型辦公軟件_計劃書_V1.22_20261009.md`）
- 網頁版開發文檔：DEV-V1～DEV-V5（含第五版修復 DEV-V5-FIX），見 `開發文檔/`
- 網頁版實作：`網頁版/`（詳見 `網頁版/README.md`）
- 桌面版：先不做

## 網頁版現況（摘要）

已做到第五版修復。能力線包括：

- 登入與角色（CEO、HR、會計、員工）
- 部門、職位與指派
- 工作紀錄（含查詢範圍、分頁、未完成工作）
- 開發者後台與多公司隔離

細節、開啟方式與各版說明以 `網頁版/README.md` 為準。
