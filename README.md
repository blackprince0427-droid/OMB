# OMB

小型辦公軟件開發流程。每一版計劃書與開發文檔獨立保存，不覆蓋舊版。

## 現行依據

- 計劃書：V1.25（`計劃書版本/小型辦公軟件_計劃書_V1.25_20261010.md`）。`計劃書版本/` 裡較早的版本都是歷史，不是現行計劃書：V1.0～V1.7（docx），以及 V1.14、V1.16、V1.20、V1.22、V1.24（md）。
- 網頁版開發文檔：DEV-V1～DEV-V7 已落地，見 `開發文檔/`。第七版是 `開發文檔/第七版內容_DEV-V7-CONTENT_20261010.md`（F-29～F-30）。任務樹取代第六版的單一專案標籤。早前停在舊目錄的草案 [PR #1](https://github.com/blackprince0427-droid/OMB/pull/1) 沒有合併；現行程式在 `web/`。
- 網頁版實作說明：`web/README.md`（應用在 `web/`。舊路徑 `網頁版/README.md` 只保留搬移說明）
- 文件地圖：`開發文檔/文件地圖.md`
- 桌面版：先不做

## 網頁版現況（摘要）

已做到第七版。能力線包括：

- 登入與角色（CEO、HR、會計、員工）
- 部門、職位與指派
- 權限指派，以及個別權限覆蓋同部門職位順序
- 工作紀錄（含歸屬／分交、分頁、未完成工作與跨人待辦）
- 工作專案任務樹（L0～L3）、刪除頁面，以及節點完成後的工作紀錄
- 開發者後台與多公司隔離

細節、開啟方式與各版說明以 `web/README.md` 為準。

## 本版不做

次日通知、從月視圖進入工作紀錄、個人事項、審批路徑、重新啟用公司、匯出匯入或本機備份、後端多人協作、甘特圖、跨公司專案、即時同時編輯、桌面版。第六版的單一專案標籤不再作為操作入口。

## 開啟

見 `web/README.md`。在 `web/` 執行 `npm install`，再 `npm run open`。

## 固定網址

網頁版準備用 Vercel 做固定網址。專案的 Root Directory 必須是 `web`。路徑不能用 `網頁版`，Turbopack 會因中文目錄建置失敗。推送到 GitHub `main` 後，線上網頁會自動更新；資料仍只在該瀏覽器的 localStorage，沒有後端同步。還沒接上 Vercel，合併與第一次連接都要心夜同意。步驟見 `web/README.md` 的「固定網址（Vercel）」。
