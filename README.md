## 網頁版現況（摘要）

已做到第七版，並已落地最小跨裝置（F-31）與 Vercel Blob 持久化（F-32）。能力線包括：

- 登入與角色（CEO、HR、會計、員工）
- 部門、職位與指派
- 權限指派，以及個別權限覆蓋同部門職位順序
- 工作紀錄（含歸屬／分交、分頁、未完成工作與跨人待辦）
- 工作專案任務樹（L0～L3）與節點完成後的工作紀錄。側欄收成「工作」：工作紀錄、未完成工作、專案；有專案時下一行才有刪除紀錄（見 `開發文檔/第七版附加_UI設計調整_20261010.md`）
- 開發者後台與多公司隔離
- 同一公司的資料在伺服器上是同一份。覆蓋前會先問；整包以本機寫入勝出。不是即時同時編輯。部署環境 omb-s4y8 把公司檔放在 Vercel Blob

細節、開啟方式與各版說明以 `web/README.md` 為準。

## 本版不做

次日通知、從月視圖進入工作紀錄、個人事項、審批路徑、重新啟用公司、匯出匯入或本機備份、即時同時編輯、甘特圖、跨公司專案、桌面版。第六版的單一專案標籤不再作為操作入口。

## 開啟

見 `web/README.md`。在 `web/` 執行 `npm install`，再 `npm run open`。

## 固定網址

線上網頁已接上 Vercel 專案 `omb-s4y8`，固定網址是 [https://omb-s4y8.vercel.app](https://omb-s4y8.vercel.app)。Root Directory 是 `web`。路徑不能用 `網頁版`，Turbopack 會因中文目錄建置失敗。推送到 GitHub `main` 後，線上網頁會自動更新。公司清單與每家公司的 JSON 存在 Vercel Blob；`BLOB_READ_WRITE_TOKEN` 已設在 production、preview、development。本機沒有這項權杖時，仍改寫 `web/data/office.json`。之後的合併與部署仍要心夜同意。說明見 `web/README.md` 的「固定網址（Vercel）」。
