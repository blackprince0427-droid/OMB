## 網頁版現況（摘要）

已做到第五版修復。能力線包括：

- 登入與角色（CEO、HR、會計、員工）
- 部門、職位與指派
- 工作紀錄（含查詢範圍、分頁、未完成工作）
- 開發者後台與多公司隔離

細節、開啟方式與各版說明以 `web/README.md` 為準。

## 本版不做

次日通知、以個別權限覆蓋職位順序、從月視圖進入工作紀錄、角色指派畫面、個人事項、審批路徑。

## 開啟

見 `web/README.md`。在 `web/` 執行 `npm install`，再 `npm run open`。

## 固定網址

網頁版準備用 Vercel 做固定網址。專案的 Root Directory 必須是 `web`。路徑不能用 `網頁版`，Turbopack 會因中文目錄建置失敗。推送到 GitHub `main` 後，線上網頁會自動更新；資料仍只在該瀏覽器的 localStorage，沒有後端同步。還沒接上 Vercel，合併與第一次連接都要心夜同意。步驟見 `web/README.md` 的「固定網址（Vercel）」。
