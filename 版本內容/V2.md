## 部門與職位

| 編號 | 本版新增 |
| --- | --- |
| F-13 | CEO 與 HR 可添加部門、為該部門添加職位，並個別設定員工權限。個別權限可以記錄；本版不讓它覆蓋職位順序。 |
| F-14 | 一人可屬多個部門。每個部門各自設定職位。 |
| R-14 | 每個部門的職位須有高低順序。數字較大者為較高職位。 |
| R-15 | 員工在每個所屬部門各有一個職位。 |

設定方式：CEO 或 HR 填寫部門名稱；在指定部門內新增職位時須填名稱與順序數字；可把員工指派到某部門並指定該部門的職位，也可再指派到其他部門。

## 工作紀錄權限

| 編號 | 本版新增 |
| --- | --- |
| F-11 | 所有公司帳戶只能處理自己的工作紀錄，不得查看或修改他人紀錄。 |
| R-11 | 任何公司帳戶不得查看或修改他人工作紀錄。 |
| F-12 | 在同一部門內，較高職位可查詢較低職位的工作紀錄。不能跨部門查詢，不能修改。 |
| R-12 | 查詢範圍只限同一部門、且職位順序較低的帳戶。 |

一人屬多部門時，只在某個部門職位較高，才可查詢該部門內較低職位帳戶的工作紀錄，不能因此查看其他部門。
