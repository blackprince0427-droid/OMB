| 編號 | 本版新增 |
| --- | --- |
| L-01 | 建立公司時必須同時建立初始 CEO。帳戶只屬於該公司。 |
| L-02 | 後台使用獨立開發人員登入，不使用公司帳戶。 |

| L-04 | 停用公司立即失效。已登入會話下次操作不得繼續。資料保留。 |
| L-05 | 同部門職位順序相同，不可互相查詢。只可查詢較低職位。 |
| L-06 | 更改職位只改已屬部門的職位，不在此項加入新部門。 |
| L-07 | 新帳戶不得共用 CEO 作為帳戶與密碼。每名使用者使用獨立帳戶，初始密碼於建立時設定。 |
| L-08 | 後台可只讀查看所選公司日誌。不可修改或刪除。公司前端不出現日誌。 |
