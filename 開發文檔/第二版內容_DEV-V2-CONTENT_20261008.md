### 1.1 設定方式

| 項目 | 已確定內容 |
| --- | --- |
| 新增部門 | CEO 或 HR 填寫部門名稱。 |
| 新增職位 | 在指定部門內新增，須填名稱與順序數字。 |
| 指派 | CEO 或 HR 為員工指定所屬部門，並指定該部門的職位。可重複指派到其他部門。 |
| 個別權限 | 可以設定。可否覆蓋職位順序，留待後續決定，本版不實作覆蓋。 |

## 2. 工作紀錄權限

| 編號 | 內容 | 狀態 |
| --- | --- | --- |
| F-11 | 所有公司帳戶只能處理自己的工作紀錄，不得查看或修改他人紀錄。 | 已完成／已落地 |
| F-12 | 在同一部門內，較高職位可查詢較低職位的工作紀錄。不能跨部門查詢，不能修改。 | 已完成／已落地 |
| R-11 | 任何公司帳戶不得查看或修改他人工作紀錄。 | 已完成／已落地 |
| R-12 | 查詢範圍只限同一部門、且職位順序較低的帳戶。 | 已完成／已落地 |

一人屬多部門時，只在某個部門職位較高，才可查詢該部門內較低職位帳戶的工作紀錄，不能因此查看其他部門。
