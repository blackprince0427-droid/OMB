## 2. F-24 權限指派畫面

### 2.1 可執行規格

| 項目 | 內容 |
| --- | --- |
| 誰 | CEO、HR（與計劃書「有權限者（CEO／HR）」一致）。其他角色不得進入指派畫面；直接開頁應顯示無權限。 |
| 做什麼 | 為公司內帳戶指派／調整**角色**，及／或調整**個別權限**記錄；畫面必須可進入、可儲存。 |
| 輸入 | 目標帳戶；角色值（既有角色集合：CEO／HR／會計／員工）；個別權限內容（延續 DEV-V2 可記錄個別權限之能力；具體欄位以實作與設計定稿為準，但必須能表達「是否覆蓋職位順序」所需資料，見 F-25）。 |
| 輸出 | 持久化至本機儲存；儲存成功後再次登入（同瀏覽器、同公司）仍可見已儲存設定。 |
| 邊界 | 不改變「更改職位只改已屬部門職位」（L-06／F-16）的既有路徑；本項是獨立的權限／角色指派畫面，不是把帳戶加進新部門。不實作審批、個人事項。跨公司不可指派（F-23 隔離延續）。 |

- [ ] 可為帳戶調整角色並儲存。
- [ ] 可為帳戶調整個別權限並儲存。
- [ ] 儲存後登出再登入，設定仍在（同瀏覽器 localStorage／既有 bundle 隔離）。
- [ ] 無此畫面則 F-24 視為未完成。

## 3. F-25 個別權限覆蓋職位順序

### 3.1 可執行規格

| 項目 | 內容 |
| --- | --- |
| 誰 | 個別權限由 CEO／HR 經 F-24 畫面設定；查詢／可見結果作用於所有會依職位順序判斷可見範圍的帳戶。 |
| 做什麼 | 當某帳戶的個別權限標記為可覆蓋時，**同部門**工作紀錄的查詢／可見規則以個別權限為準，**不以職位順序為唯一依據**。 |
| 輸入 | 個別權限記錄（含「覆蓋職位順序」相關設定）；既有部門指派與職位順序。 |
| 輸出 | 查詢範圍計算結果改變：覆蓋開啟後，可見範圍依個別權限；覆蓋未開或無記錄時，維持既有職位順序規則（含 L-05 同階不可互查）。 |
| 邊界 | 僅覆蓋「同部門職位順序的查詢／可見規則」；不自動授權跨部門查詢（計劃書未承諾跨部門）。不修改他人紀錄（查詢仍為只讀，除非另有歸屬／編輯規則，見 F-26）。 |

### 3.2 可見性（依計劃書，最小矩陣）

| 情境 | 覆蓋未開（延續現況） | 覆蓋開啟後 |
| --- | --- | --- |
| 同部門、職位較高查較低 | 可查（只讀） | 以個別權限為準（可放寬或收斂，不以職位順序為唯一依據） |
| 同部門、職位同階 | 不可互查（L-05） | 以個別權限為準 |
| 同部門、職位較低查較高 | 不可查 | 以個別權限為準 |
| 不同部門 | 不可跨部門查 | 計劃書未承諾跨部門；維持不可跨部門，除非個別權限規格另有明確欄位（見下方歧義） |

### 3.3 檢查清單

- [ ] 可為帳戶設定「覆蓋職位順序」相關個別權限並儲存（依賴 F-24）。
- [ ] 覆蓋開啟後，可見範圍不以職位順序為唯一依據（用至少一組同部門較高／同階／較低對照驗證）。
- [ ] 覆蓋未開時，行為與第五版修復後職位順序規則一致（含同階不可互查）。
- [ ] 驗收不以「即時多人同時在線」為前提；以輪流登入同一瀏覽器驗證。

## 4. F-26 歸屬／分交

### 4.1 可執行規格

| 項目 | 內容 |
| --- | --- |
| 誰 | 工作紀錄帶「歸屬帳戶」。新建時可指定歸屬；分交＝將既有紀錄的歸屬改為另一帳戶。 |
| 做什麼 | 改歸屬後：**新歸屬者可編輯**該筆；**原歸屬者不可再改**該筆。單機下**無即時通知**，分交僅寫入可見變化（對方須輪流登入後才看到）。 |
| 輸入 | 目標紀錄；新歸屬帳戶（同公司）。 |
| 輸出 | 紀錄上的歸屬欄位更新；編輯權限隨歸屬轉移。 |
| 邊界 | 不實作推播／郵件／次日通知。分交不是審批。跨公司歸屬禁止。本人新建默認歸屬為自己（與「可指定歸屬」相容：未指定則本人）。 |

### 4.2 編輯／可見邊界（依計劃書）

| 角色相對該筆 | 改歸屬前（歸屬＝A） | 分交後（歸屬＝B） |
| --- | --- | --- |
| 帳戶 A | 可編輯（原歸屬） | 不可再改該筆 |
| 帳戶 B | （非歸屬；可見性另依職位／個別權限） | 可編輯（新歸屬） |
| 其他有查詢權者 | 只讀查詢（若權限允許） | 只讀查詢（若權限允許）；不可因查詢而取得編輯權 |

### 4.3 檢查清單

- [ ] 新建工作紀錄可指定歸屬帳戶（或默認本人）。
- [ ] 可將歸屬由 A 改為 B（分交）。
- [ ] 分交後：以 B 登入可編輯該筆；以 A 登入不可再改該筆。
- [ ] 分交當下無即時通知；以輪流登入驗證「僅寫入可見變化」。
- [ ] 不可把歸屬指到其他公司帳戶。

## 5. F-27 跨人待辦

### 5.1 可執行規格

| 項目 | 內容 |
| --- | --- |
| 誰 | 任一已登入公司帳戶；列表內容依「歸屬＋權限」聚合。 |
| 做什麼 | 提供跨人待辦列表，至少能區分／涵蓋：**別人指給我的**（歸屬為我、由他人分交或指定）與 **我可見的**（依職位順序或 F-25 個別權限可查、但不一定歸屬為我）。 |
| 輸入 | 目前登入帳戶；公司內工作紀錄的歸屬欄位；查詢／可見規則（職位順序＋個別權限覆蓋）。 |
| 輸出 | 待辦列表（可為獨立頁或既有「未完成」頁之擴充；計劃書未鎖定 UI 形態，但必須可依歸屬與權限顯示）。 |
| 邊界 | **跨人＝同一瀏覽器輪流帳戶可見，不是即時多人協作。** 不做雲端任務牆、不做即時同步。不做審批狀態機。 |

### 5.2 檢查清單

- [ ] 帳戶 A 將一筆未完成分交／歸屬給 B 後，以 B 登入可見於「別人指給我的」（或等價區段）。
- [ ] 以較高職位（或覆蓋後有權限）帳戶登入，可在「我可見的」看到權限允許之他人未完成項（只讀，除非自己是歸屬者）。
- [ ] 無權限／非歸屬者看不到不應見的項。
- [ ] 驗收步驟明確使用「登出 → 換帳戶登入」輪流操作，不要求雙開同時協作。
